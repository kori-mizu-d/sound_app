# 外部の音が鳴るまでの時間

## ローカルで試す

Python 3 をインストールし、このフォルダーで次を実行してください。

```powershell
python app.py
```

ブラウザーで <http://127.0.0.1:8000> を開きます。終了するときは、ターミナルで `Ctrl+C` を押してください。

## 使い方

1. **マイクを接続**を押し、ブラウザーのマイク使用を許可します。
2. 検出感度を周囲の音に合わせて調整します。右に動かすと小さな音に反応します。入力レベルのバーを見ながら、周囲の音より測定したい音が大きくなるよう調整してください。
3. **スタート**を押し、マイクが外部の音を検知するまでの時間を確認します。

音の検知はブラウザー内で行い、音声を録音したりサーバーへ送信したりしません。周囲の騒音やマイク・ブラウザーの処理遅延により、測定値に誤差が生じます。

## GitHub Pagesで公開する

このサイトはブラウザー内でマイクの音を検知するため、公開時にPythonサーバーは必要ありません。ページ本体は `public/index.html` にあり、GitHub ActionsがGitHub Pagesへ自動で公開します。マイクを使うにはHTTPS接続が必要です。GitHub Pagesの公開URLはHTTPSに対応しています。

1. GitHubで新しいリポジトリを作成します。一般公開する場合は、リポジトリも **Public** にしてください。
2. この `reaction_sound_site` フォルダーの中身をリポジトリにアップロードして、`main` ブランチへ反映します。`.github/workflows/pages.yml` も含めてください。
3. GitHubリポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions** タブでデプロイが完了したら、**Settings → Pages** に表示されるサイトのURLを開きます。以後、`main` ブランチへの更新時に自動で再公開されます。

リポジトリ名が `sound-timer` の場合、公開URLは通常 `https://<GitHubユーザー名>.github.io/sound-timer/` です。

## 動作について

スタートを押した時刻から、マイク入力の音量が設定したしきい値を超えるまでを計測します。測定値にはマイク、ブラウザー、周囲の環境による遅延や誤差が含まれます。
