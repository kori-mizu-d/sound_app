## 説明

本サイトは、筆者が物理チャレンジ（国際物理オリンピック日本予選）の1次レポート用として企画したものの、実装上の困難から一度は断念したアプリケーションを、生成AIを活用して再構築したものです。


## 使用方法

1. **マイクを接続**を押し、ブラウザのマイク使用を許可します。
2. 検出感度を調整します。上段のバーを右に動かすことで、より小さな音に反応するようになります。下段のバーが現在の周囲の音を表すので、両者を見比べることで、閾値が周囲の音より大きくなるように調節してください。
3. **スタート**を押し、マイクが外部の音を検知するまでの時間を確認します。


## 補足

音の検知はブラウザ内で行うので、音声は録音されません。<br>
測定値には、マイクやブラウザによる遅延が含まれます。
